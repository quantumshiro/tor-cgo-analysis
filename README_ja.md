# Tor CGOメモリフォレンジック研究

このリポジトリは、C TorプロセスのメモリからCounter Galois Onion（CGO）の回路状態を復元し、保存済みの通信記録と結び付けるフォレンジック手法の研究成果物です。論文の評価対象はリリースタグ`v0.0.1`で固定しています。

## 主要な結果

本手法は、暗号鍵に見えるバイト列を単独で検索しません。Torが保有する回路から入口ホップと後続ホップをたどり、所有関係、構造、状態、時間、暗号認証を順に検証します。

- 複数のC Tor 0.4.9系ビルドで、144/144回路と432/432ホップを復元しました。
- 独立した10回の取得物で、回路の所有関係からTransport Layer Security（TLS）とCGOの二層を経てリレー本文へ至る証拠鏖を10/10回で検証しました。各回で493/493バイトの本文が一致しました。
- CGO状態の負対照7,168件、TLSの負対照、実行ファイル不一致、欠損メモリセグメントを用いて、誤った候補を受理しないことを評価しました。

本結果は、現在のCGO状態から過去の通信全体を復号できることや、Tor利用者の匿名性を遠隔から破壊できることを示していません。

## 収録内容

- `paper/`：日本語論文のLaTeX原稿、参考文献、主張と成果物の対応表
- `forensics/`：DWARF型情報とExecutable and Linkable Format（ELF）コアダンプを読むオフライン解析器
- `experiments/`：証拠マニフェストの作成、TLS復号、CGO再生、負対照評価のスクリプト
- `results/`：機微情報を除いた集計結果、個別評価結果、SHA-256一覧
- `research/E1_E5_INTEGRATED_PIPELINE_ja.md`：二層復号実験の設計と評価条件
- `docker/Dockerfile`と`requirements.txt`：解析環境の構築情報

C Tor、Arti、Tor仕様、Chutneyの第三者ソースは収録していません。評価に使用したコミットは`results/source-commits.txt`に固定しています。

## 整合性の検証

リポジトリのルートで次のコマンドを実行します。

```sh
shasum -a 256 -c results/SHA256SUMS.paper-v3
```

公開用アーカイブは、固定済みのファイル一覧から再生成できます。

```sh
paper/build_public_supplement.sh
```

## 公開範囲

公開版には、生のコアダンプ、Packet Capture（PCAP）、TLS通信秘密、CGO鍵、復号済み通信を含めていません。このため、公開版だけでメモリ取得からの二層復号を再実行することはできません。解析手順、集計結果、負対照、成果物の整合性は公開版で検証できます。

すべての実験は管理下の隔離ネットワークで行い、第三者のTor通信を観測していません。
