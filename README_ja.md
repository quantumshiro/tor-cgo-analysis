# Tor CGOメモリフォレンジック研究

このリポジトリは、C TorプロセスのメモリからCounter Galois Onion（CGO）の回路状態を復元し、保存済みの通信記録と結び付けるフォレンジック手法の研究成果物です。論文の評価対象はリリースタグ`v0.0.4`で固定しています。

## 主要な結果

本手法は、暗号鍵に見えるバイト列を単独で検索しません。Torが保有する回路から入口ホップと後続ホップをたどり、所有関係、構造、状態、時間、暗号認証を順に検証します。

- 複数のC Tor 0.4.9系ビルドで、144/144回路と432/432ホップを復元しました。
- Tor Project公式Debianパッケージのストリップ済みTor 0.4.9.17と、対応する外部デバッグシンボルを用いた3回の独立起動で、36/36回路と108/108ホップを復元しました。
- 同じ公式パッケージを用いた別の6回では、公式Tor 0.4.9.17ソースから構築した再生器により、一意なCGO認証に6/6回成功しました。評価用マーカーを含むリレーDATAセル本体は5件、SENDMEセルは1件でした。全36候補の復元結果は、旧再生器の結果と一致しました。
- 独立した10回の取得物で、回路の所有関係、Transport Layer Security（TLS）レコード、CGO層、リレー本文の対応を10/10回で検証しました。各回で493/493バイトの本文が一致しました。
- ストリームを一時停止せず、停止時点をセルやTLSレコードの境界に合わせなかった6回の独立取得でも6/6回成功しました。TLS書込みレコード番号6種、宛先ホップ1と2を含みます。
- CGOとTOR1が混在する10回路は方式を分類したうえで、CGO専用処理へは投入しませんでした。
- CGO状態の負対照7,168件、TLSの負対照、実行ファイル不一致、欠損メモリセグメントを用いて、誤った候補を受理しないことを評価しました。

本結果は、現在のCGO状態から過去の通信全体を復号できることや、Tor利用者の匿名性を遠隔から破壊できることを示していません。

## 収録内容

- `paper/`：日本語論文のLaTeX原稿、参考文献、主張と成果物の対応表
- `forensics/`：DWARF型情報とExecutable and Linkable Format（ELF）コアダンプを読むオフライン解析器
- `experiments/`：証拠マニフェストの作成、TLS復号、CGO再生、負対照評価のスクリプト
- `results/`：機微情報を除いた集計結果、個別評価結果、SHA-256一覧
- `research/E1_E5_INTEGRATED_PIPELINE_ja.md`：TLSレコードとCGO層を順に処理する実験の設計と評価条件（ファイル名は過去版との対応のため維持）
- `research/TERMINOLOGY_AUDIT_ja.md`：Tor仕様の用語と本稿独自の評価ラベルを分離した監査結果
- `docker/Dockerfile`と`requirements.txt`：解析環境の構築情報

C Tor、Arti、Tor仕様、Chutneyの第三者ソース一式は収録していません。評価用に追加したC TorのCGO再生テストだけは、変更済みソース`third_party/tor-cgo-audit/src/test/test_crypto_cgo.c`を収録します。基準ソースのコミットは`results/source-commits.txt`に固定しています。

## 整合性の検証

リポジトリのルートで次のコマンドを実行します。

```sh
shasum -a 256 -c results/SHA256SUMS.paper-v6
```

公開用アーカイブは、固定済みのファイル一覧から再生成できます。

```sh
paper/build_public_supplement.sh
```

## 公開範囲

公開版には、生のコアダンプ、Packet Capture（PCAP）、TLS通信秘密、CGO鍵、復号済み通信を含めていません。このため、公開版だけで保存済み取得物の復号を再実行することはできません。公開版では、解析コードの監査、秘密を除いた個別結果からの集計再生成、結果ハッシュの検証ができます。完全な再現は、収録した取得スクリプトで管理下の隔離網に新しい取得物を生成して行います。主張ごとの再現可能範囲は`paper/ARTIFACTS_ja.md`に記載しています。

すべての実験は管理下の隔離ネットワークで行い、第三者のTor通信を観測していません。
