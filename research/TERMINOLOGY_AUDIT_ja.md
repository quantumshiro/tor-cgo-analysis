# 論文の用語監査

監査日：2026年11月14日

対象：`paper/jsac_cgo_forensics_ja.tex`

## 結論

Tor仕様またはC Tor実装に由来する用語と、本稿が評価のために定義したラベルを分離した。既存用語のように見える独自表現は削除し、処理条件または観測結果を直接記述した。

## 原典で確認した用語

次の語は、Tor仕様、C Tor実装、TLSまたはELF/DWARFの仕様で確認できるため、その位置づけを初出で説明した上で使用する。

| 用語 | 本稿での意味 | 主な確認先 |
|---|---|---|
| Counter Galois Onion（CGO） | Proposal 359が定義するオニオン暗号方式 | Tor Proposal 359 |
| relay cell / relay message | Torが回路上で処理するセルと、そのペイロード内のメッセージ | Tor仕様、Proposal 359 |
| origin circuit | クライアントが起点となるC Torの回路 | C Torの`origin_circuit_t` |
| `global_origin_circuit_list` | C Torが保持するクライアント起点回路のリスト | C Torソース |
| `cpath` / `crypt_path_t` | 入口ホップを起点とする暗号経路 | C Torソース |
| forward / backward | クライアントからリレー側へ向かう前方向と、その逆の後方向 | Tor仕様、Proposal 359 |
| AEAD、TLSレコード、書込みレコード番号 | TLS 1.3レコードの認証復号に必要な標準概念 | TLS 1.3仕様、OpenSSL実装 |
| GNU Build ID、`NT_FILE`、DWARF | 実行ファイルの識別、コアダンプの写像、型情報 | ELF/DWARF仕様、GDB文書 |
| Wilsonスコア区間 | 二項比率の信頼区間 | 統計学の既存手法 |

英語の識別子はソースコードと対応させる必要がある箇所だけ`code`書体で残す。日本語本文では「リレーセル」「前方向」「後方向」「コアダンプ」「外部デバッグシンボル」のように表記する。

## 本稿が定義した評価ラベル

E1からE5とモードA・BはTor仕様の用語ではない。本稿の処理条件を参照しやすくするための評価ラベルである。そのため、本文で独自ラベルであることと各条件を明示する。

- E1：所有リストを完全に列挙できた。
- E2：回路型、リスト添字、入口起点の経路構造を検証できた。
- E3：活動中の回路について、全ホップの暗号方式と初期化状態を検証できた。
- E4：コアダンプ内のTLS状態に対応する保存TLSレコードを認証復号できた。
- E5：CGO認証が一意に成立するセルと宛先ホップを特定できた。

これらのラベルだけで処理内容を説明せず、表または本文に成立条件を併記する。

## 削除または書換えを行った表現

| 旧表現 | 問題 | 書換え方針 |
|---|---|---|
| 安全側に復元 | 定着した用語ではなく、何を確定したかが不明 | 「検証条件を満たした結果だけを確定する」 |
| 安全側停止 | 停止の条件と出力が不明 | 「平文を出力しない」「復号処理へ渡さない」 |
| 取得時点同期型 | 本稿独自の圧縮表現 | コアダンプ取得時点とPCAPの対応条件を直接記述する |
| 境界制御／境界非選択 | 何の境界かが読み手に伝わらない | ストリーム停止の有無と、停止時点をセルやTLSレコードの境界に合わせたかを記述する |
| 所有グラフ | Tor仕様の用語ではない | 「Tor構造体間のポインタ関係」 |
| 復元完全性 | 独自の抽象語 | 「読取りの成否と列挙の完了状態」 |
| 証拠鎖 | 法的なchain of custodyと混同し得る | 「検証可能な対応関係」 |
| 方式未確定 | 実装ラベルに見える | 「方式を判定不能とし、確立したとは報告しない」 |
| 二層復号 | 独自の短縮表現 | 「TLSレコードを復号した後にCGO層を処理する」 |

## 外来語の表記

英単語に日本語の助詞を直接つなげた表現を修正した。例えば、`streamを停止`は「ストリームを停止」、`manifestへ記録`は「対象回路一覧へ記録」、`profile検査`は「プロファイル検査」、`relay本文`は「リレー本文」とした。

## 残した固有名詞と識別子

CGO、TOR1、C Tor、Arti、Chutney、OpenSSL、GDB、DWARF、ELF、PCAP、TLS、AEAD、POLYVALは、仕様、実装、方式またはファイル形式の名称であり、造語ではない。`origin_circuit_t`、`crypt_path_t`、`global_origin_circuit_list`、`cpath`はC Torソースと照合するため、コード識別子として残した。
