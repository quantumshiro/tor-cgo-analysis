# 回路構造・TLSレコード・CGO状態を連続して検証する処理の評価

> 注：ファイル名は過去版からの参照を保つために維持している。本文では独自の段階名を使わず、実際に確認した事項を記す。

## 目的

TLSレコードを復号した後にCGO層を処理する10回の評価では、コアダンプからTLSとCGOの秘密を抽出できることに加え、所有回路一覧に含まれる回路について、入口からのホップ順、暗号コンテキスト、入口リンクのTLSレコード、CGO認証済み本文を順に対応付けられるかを確認した。

## 入力と正解の分離

復号処理が読む入力は、各独立起動で保存した次の三種類である。

- クライアントのELFコアダンプ
- 対応する実行ファイルとDWARF
- コアダンプ取得時点をまたぐ入口リンクPCAP

構造解析器は所有回路一覧を完全列挙する。構造検査に合格し、全ホップでCGO暗号コンテキストの初期化を確認できた回路を`e3-circuit-manifest.json`へ出力する。このファイル名は過去版との互換性のために維持している。TLS秘密抽出器とCGO秘密抽出器はこの回路一覧を必須入力とし、所有回路一覧の添字、回路アドレス、二種類の回路ID、ホップ数、入口を起点とするホップアドレスが一致する回路だけを処理する。

Control Protocol由来の正解回路ID、動的フック由来の正解セル、正解ホップ、正解平文は、復号終了後の評価器だけが読む。

## 実施手順

各取得物について次を実行した。

```sh
experiments/postprocess_pcap_core_case.sh SOURCE OUTPUT
```

出力には、実行ファイルの対応検査、構造解析、暗号状態を検証済みの回路一覧、TLSとCGOの状態、TLS認証結果、全セル候補、全候補のCGO処理結果、復元終了後の正解データとの比較結果が含まれる。

10回の集計には`experiments/evaluate_full_pcap_repetitions.py`を使用した。正解分離は`experiments/audit_evidence_separation.py`で別に検査した。

## 結果

集計ファイルは`results/open-circuit-impact/independent-v3/summary.json`である。

| 検証項目 | 成功 |
|---|---:|
| 所有回路一覧の完全列挙 | 10/10 |
| origin magic、一覧内の添字、入口からたどる閉路の整合 | 10/10 |
| 回路が活動中であること、全ホップがTor内部のOPEN状態であること、CGO暗号コンテキストが初期化済みであること | 10/10 |
| TLS AEAD認証とセル列挙 | 10/10 |
| 一意なCGO認証と本文復元 | 10/10 |

各回の共通結果は次のとおりである。

- OpenSSL内部状態から暗号スイート`TLS_AES_256_GCM_SHA384`を直接取得した。
- コアダンプ内の書込みレコード番号は7だった。
- TLS認証済みレコードから対象入口回路IDのセルを7件列挙した。
- CGO認証に成功した候補は7件中1件だけだった。
- 認証ホップはホップ2だった。
- 終了後評価で、認証候補が正解候補と一致した。
- CGOタグを除く493/493バイトが正解平文と一致した。

固定条件下の10/10に対する二側95% Wilson区間は72.25--100%である。これは一般環境での成功率ではなく、同じTor、OpenSSL、OS、アーキテクチャ、暗号スイート、取得境界における反復性を示す。

## 解釈

旧処理でもTLSレコードの復号とCGO層の処理は10/10で成功していたが、所有関係、入口からのホップ順、暗号コンテキストの初期化に関する検証結果を、秘密抽出器の必須入力としていなかった。修正後は、これらの検証に合格しない回路からTLSやCGOの秘密を抽出しない。また、最初に認証した候補を採用せず、全候補を処理した後にCGO認証に成功した候補が厳密に一件であることを要求する。

したがって本評価が支える主張は、「所有関係、入口からのホップ順、暗号状態、入口リンクのTLS状態、保存PCAP、CGO認証済み本文を相互に対応付ける処理を、固定した管理下環境で10回再現した」である。

## 限界

- 中心評価はDebian arm64、Tor 0.4.9.16、OpenSSL 3.0.22に限る。
- 全回が書込みレコード番号7、ホップ2、同じ暗号スイートだった。
- TLSレコードの復号後にCGO層を処理する評価は、全ホップがCGOの回路だけを対象とする。
- 取得時はストリームを一時停止し、安全な処理境界を作った。
- 生のコアダンプ、TLS秘密、CGO秘密は公開対象にしない。
